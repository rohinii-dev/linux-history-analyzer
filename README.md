# linux-history-analyzer
A Python tool that analyzes Linux command history and identifies frequently used commands.

Features:
1.Counts the total number of commands.
2.Identifies the most frequently used command.
3.Displays how many times each command was used.

How to Run:
1.Download the project files.
2.Make sure Python 3 is installed.
3.Open a terminal in the project folder.
4.Run the following command:
python3 history_analyzer.py history.txt (for macOS users)

Input:
The program reads commands from history.txt.
